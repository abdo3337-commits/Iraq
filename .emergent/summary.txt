The Orange Bus (الباص البرتقالي), now Abu Al Gharbiya (أبو الغربية), is a smart transportation application for Anbar Governorate, Iraq, connecting passengers with small car drivers. The goal is to provide safe, comfortable, and flexible transport with competitive features.

**Core MVP Features (Implemented):**
*   Real-time car tracking, nearest car identification, and estimated arrival times.
*   Diverse payment systems (initially cash-only).
*   Rating and review system for users and drivers.
*   Multi-language support (Arabic primary, English planned).
*   Separate user interfaces for passengers and drivers.
*   Geographical focus on Anbar, Iraq.
*   Professional design similar to Careem/Uber.
*   Full authentication system (login/signup, JWT for security).
*   Backend for users, rides, and ratings (MongoDB, FastAPI).
*   Interactive maps using OpenStreetMap (Leaflet.js in WebView), including current location, origin/destination selection, and Anbar city/landmark search.
*   In-app chat system (WebSocket) for rider-driver communication.

**Advanced Features (Requested/Pending):**
*   **Pre-booking:** Schedule rides in advance with date/time selection, backend management, notifications, and cost estimation.
*   **Open Rides:** Time-based payment option for flexible trips with no fixed destination, requiring precise time tracking.
*   **Diverse Car Categories:** Standard and VIP options with different pricing, requiring UI and backend updates to link drivers/cars to categories.
*   **Delivery Service:** Separate UI, pricing based on distance/package size, driver acceptance, real-time package tracking, and order management.
*   **Corporate Delivery:** Special interface for businesses, managing multiple requests, and reporting.

The project emphasizes a mobile-first approach, quality UX/UI, and utilizing modern Expo/React Native libraries.
