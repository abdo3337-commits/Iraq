<product_requirements>
The application, originally الباص البرتقالي and now rebranded as أبو الغربية (Abu Al-Gharbiya), is a smart transportation platform for Anbar Governorate, Iraq, connecting passengers with small car drivers for safe, comfortable, and flexible transport.

**Core MVP Features Implemented:**
*   Real-time car tracking, nearest car identification, and ETA.
*   Cash-only payment system (initial).
*   User and driver rating/review system.
*   Multi-language support (Arabic primary).
*   Separate UIs for passengers and drivers.
*   Geographical focus on Anbar, Iraq.
*   Careem/Uber-like professional design.
*   Full authentication with JWT.
*   FastAPI backend with MongoDB for users, rides, and ratings.
*   Interactive maps using OpenStreetMap (Leaflet.js in WebView) with location selection and search.
*   In-app chat system via WebSockets.

**Advanced Features Requested/Pending:**
*   **Pre-booking:** Scheduled rides with date/time, cost estimation, notifications.
*   **Open Rides:** Time-based payment for flexible trips without a fixed destination.
*   **Diverse Car Categories:** Standard and VIP options with differentiated pricing.
*   **Delivery Service:** Dedicated UI for package requests, distance/size-based pricing, driver acceptance, real-time tracking, order management.
*   **Corporate Delivery:** Special interface for businesses with multiple requests and reporting.
*   Integration of Zen Cash and international card payment gateways (Visa/Mastercard).

The project prioritizes mobile-first design, high UX/UI quality, and modern Expo/React Native best practices.
</product_requirements>
